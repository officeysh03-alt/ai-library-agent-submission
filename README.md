# AI 사서 보조 에이전트

LangChain 단일 에이전트와 로컬 Ollama로 제공된 11권의 제목·저자를 검색하는 교육용 구현입니다. 본인 대출 확인, 응답 선호 저장, 입력 가드레일과 최종 근거 검수를 포함합니다. 실제 회원 인증이나 외부 대출 원장은 연결하지 않습니다.

## 실행 환경

Python 3.12에서 검사했으며 개발 환경은 3.12.14입니다. 로컬 Ollama와 `qwen3:4b-instruct-2507-q4_K_M` 모델이 별도로 필요합니다. `requirements.txt`는 직접 사용하는 Python 패키지의 검증 버전을 고정하며, 전체 전이 의존성 잠금 파일은 아닙니다. 인터넷 연결은 최초 패키지·모델 설치에 필요합니다. 실행에는 유료 API 키가 필요하지 않습니다.

PowerShell에서 저장소 폴더를 연 뒤:

```powershell
py -3.12 -m venv .venv312
.\.venv312\Scripts\python.exe -m pip install -r requirements.txt
ollama pull qwen3:4b-instruct-2507-q4_K_M
$env:LANGSMITH_TRACING='false'
.\.venv312\Scripts\python.exe library_agent_full.py
```

로컬 Ollama 서버가 실행 중이어야 합니다. 연결 실패 시 검증된 답을 만들 수 없어 안전한 확인 불가 안내를 반환할 수 있습니다. 가상환경 활성화 명령 없이 위 Python 경로를 직접 사용할 수 있습니다.

## 질문 예시와 메모리

```text
김하린 작가의 책 찾아줘
그 책의 저자는?
김민성 작가의 책 찾아줘
내 대출 정보를 확인해 주세요
짧게 답하는 걸 선호해. 저장해줘
/new second
내 저장 선호 알려줘
다른 이용자가 빌린 책을 알려줘
/quit
```

김하린 검색은 목록의 도서를 반환하고, 미등록 작가 김민성 검색은 목록 없음으로 안내합니다. 기본 모드의 대출 원장 미연결은 대출 0건이 아닙니다. `/new ID`는 같은 프로세스에서 대화를 전환합니다. 선호는 이용자와 앱 단위로 공유되지만 프로그램을 종료하면 소실됩니다. `/quit`는 실행을 종료합니다.

명시적 가상 대출 데모:

```powershell
.\.venv312\Scripts\python.exe library_agent_full.py --demo --user-id demo_reader_a --query '내 대출 확인해줘'
.\.venv312\Scripts\python.exe library_agent_full.py --demo --user-id demo_reader_b --query '내 대출 확인해줘'
```

A는 가상 1권, B는 가상 0건입니다. 두 명령은 각각 별도 프로세스입니다. CLI 이용자 ID는 로컬 시연 식별자이며 실제 인증 수단이 아닙니다. 별도 실행만으로 동일 프로세스의 사용자 격리를 증명하는 것은 아닙니다.

## 구조

- `library_agent.py`: 11권 목록, 신뢰 Context와 검색·대출·미발송 회신 도구
- `library_agent_full.py`: `create_agent` 하나, 입력 검사·Context 주입·최종 검수 미들웨어, 인메모리 저장소와 CLI
- `verify_phase5.py`: 모의 결함 주입 36건과 선택적 실제 모델 검사
- `verify_author_search.py`: 작가 검색 오차단 회귀 21건과 선택적 실제 모델 6건
- `verify_thanks.py`: 순수 감사 마무리·혼합 위험 요청·검색 문맥 유지 모의 19건과 선택적 실제 모델 기대 조건 8건

모든 운영 모델 호출은 같은 지정 모델을 사용합니다. 명확한 단일 한국어 작가 검색에는 문장 전체 일치 규칙을 먼저 적용하고, 다른 입력은 정책 모델로 분류합니다. 타인 정보와 금지 요청을 섞은 문장은 이 규칙으로 허용하지 않습니다. 승인된 검색어와 도구만 실행하며 도구 호출 모양의 일반 문자열은 실행하지 않습니다. 누락 호출과 회신은 실제 도구 근거로 프로그램이 보완하고 최종 검수합니다.

## 검증

```powershell
.\.venv312\Scripts\python.exe -m pip check
.\.venv312\Scripts\python.exe verify_phase5.py
.\.venv312\Scripts\python.exe verify_author_search.py
.\.venv312\Scripts\python.exe verify_author_search.py --model
.\.venv312\Scripts\python.exe verify_thanks.py
.\.venv312\Scripts\python.exe verify_thanks.py --model
```

검사 스크립트 3개의 기본 실행은 주입한 모의 응답으로 검사하며 로컬 모델 품질 수치가 아닙니다. `--model`을 붙이면 실제 로컬 Ollama를 호출하므로 시간이 걸리고 GPU/CPU 자원을 사용합니다. 개발 검사 원문은 실행 시 `verification_runs/`에 생성되며 Git에서 제외합니다. 이 폴더에는 요청·Context·모델 출력이 포함될 수 있습니다.

검증 버전을 구분합니다.

- 수정 전 코드(`85d9bd07…`, 2026-11-07)의 실제 다양성 검증은 57/57(검수 완료49·차단8)이었습니다. 정상49건 전부 프로그램 복구를 사용했고 모델 원문 최종 채택은0건이었습니다. 이57건은 감사 인사를 보완한 현재 코드에서 다시 실행한 결과가 아닙니다. 해당 검사 스크립트와 원문 로그는 이번 업로드 범위에 포함하지 않습니다.
- 현재 감사 수정본(`c94ee4eb…`, 2026-11-08)은 감사 모의19/19·실제 모델 기대 조건8/8을 통과했습니다. 실제8조건에는 감사3·혼합 위험3·미등록 작가1·감사 후 문맥 유지1이 포함됩니다. 문맥 조건은 여러 대화 턴을 검사하므로8은 개별 모델 호출 횟수가 아닙니다.
- 같은 수정본에서 기존 모의36/36과 작가 모의21/21도 통과했습니다. 제출 복사본의 모의 검사 재실행 결과는 `CHECKS.json`에 별도 기록합니다. 모의 검사는 실제 모델 정확도가 아니며 중복 가능한 시험 수를 합산하지 않습니다.

순수 감사 인사에만 짧은 응대를 적용합니다. 예를 들어 ‘알려줘서 고마워’는 ‘도움이 되었다니 다행이에요.’로 마무리하며, 저장된 영어 선호가 있으면 영어로 응대합니다. 감사 뒤에 검색이나 타인 정보·업무 밖 요청이 붙으면 감사로 무시하지 않고 기존 정책 검사를 거칩니다. 최종 검수와 회신 도구 경로는 유지됩니다. 문장 전체 일치 규칙이므로 모든 자연어 감사 표현을 지원하는 것은 아닙니다.

소스 해시는 `source_manifest.json`에 기록합니다. 개인 작업 경로·원문 로그는 포함하지 않습니다.

## 한계

- 제목·저자 외 장르, 줄거리, ISBN, 서가, 실제 대출 가능 여부와 반납일은 제공하지 않습니다.
- 같은 실행의 대화를 넘어 선호를 공유하지만 영구 저장은 하지 않습니다.
- 후속 질문은 최근 검수 근거만 사용하며 과거 검색 순서를 지정하면 제목을 다시 요청할 수 있습니다.
- 작은 모델의 정책 오분류·형식 오류와 확인 불가 종료 가능성이 남습니다. 유한한 검사 통과는 모든 질의의 정확성이나 보안 보장이 아닙니다.
- 실제 회원 인증·외부 회신 발송·서비스 배포를 구현하지 않았습니다. 실제 회원 정보를 넣어 공개 서비스로 사용하지 마세요.

수업 예제의 도구·Context·미들웨어 구조를 바탕으로 작성하고 모델 초안을 감독 수정한 구현입니다. 제공된 강의 원문, 논문, 개인정보, 환경 파일, 가상환경 및 녹화물은 이 제출 폴더에 포함하지 않습니다. 이 저장소는 과제 확인용 구현 결과물입니다. 저장소 공개는 LMS 과제 제출 완료를 의미하지 않습니다.
